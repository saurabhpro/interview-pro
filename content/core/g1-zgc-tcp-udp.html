Two boundaries interviewers test

The win is not recalling four definitions. It is identifying where work, guarantees and recovery responsibility live.

1. G1 vs ZGC: where does relocation happen?

G1 moves selected live objects during stop-the-world evacuation. ZGC relocates concurrently and makes reference access safe with barriers.

G1: app ─────┤ STW evacuation ├───── app
ZGC: app ──────────────────────────── app
         concurrent mark + relocation
              tiny coordination pauses

JDK 26 defaults to G1 on server-class machines. ZGC is generational-only and enabled with -XX:+UseZGC. Benchmark the application rather than choosing from collector reputation.

2. TCP vs UDP: transport is not the application protocol

Application  REST/HTTP | FIX | WebSocket | binary feed
Transport    TCP      | UDP | QUIC-over-UDP
Network      IP
Link         Ethernet / Wi-Fi

Both TCP and UDP can be raw socket programming. REST normally means HTTP semantics, not TCP.

TCPUDP
ShapeReliable ordered byte streamIndependent datagrams
FramingApplication adds message boundariesDatagram boundary retained
LossRetransmit; later bytes waitLater packets continue; app sees a gap
Market-data useRecovery, sessions, orders, snapshotsHigh-rate multicast incrementals

Concrete recovery: receive sequences 5001 then 5003. Mark the book stale, recover 5002 or a snapshot over a reliable channel, rebuild, then publish healthy state. UDP loss is expected; silently serving the gapped book is the defect.
